How to deploy Windows onto a Linux VPS with Fomze Installer.

  1. On the Home tab pick a Windows version and options (port, browser). The command is ready instantly.
  2. Copy the command and run it over SSH on your fresh Linux VPS (as root).
  3. Watch progress on the Live status link — it shows the download bar, stages and time remaining.
  4. When it turns Online, connect over RDP to the Address (IP:Port) with the username and password shown.

ⓘ The command runs on your Linux VPS and reinstalls it as Windows — the disk is wiped, so only run it on a server you intend to convert.
